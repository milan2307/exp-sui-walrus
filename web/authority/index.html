Authority Portal — What This Does
This portal is for institutional parties: shipping lines, port authorities, customs authorities, and government officials. Each party can only write events they are authorised for — the Move contracts enforce this at the protocol level. Institutional login via zkLogin with government/corporate credentials is planned for Phase 3.

Already live: Port authorities can use the CLI today to call gate_in(), load_on_vessel(), and discharged() directly. This portal is the web interface for that functionality.
Available Actions — What You Can Do From This Portal
📦
Register Container (Gate-In)
Record container arrival at your terminal. Creates an immutable gate-in timestamp on Sui. Demurrage clock starts from this exact moment.
CLI Available Now
🚢
Record Vessel Events
Load on vessel, discharge at destination. Each event creates an immutable on-chain record. Shipping line calls these; port authority confirms.
CLI Available Now
🛃
Issue Customs Clearance
Sign customs release on-chain. Both portals reflect the clearance instantly. Requires customs_clearance.move.
Phase 3

Issue Bill of Lading
Shipping line issues the BL as a Sui NFT to the consignee. 23 DCSA eBL 3.0 fields. Seal encryption available for sensitive cargo.
CLI Available Now

Issue Phytosanitary Certificate
National plant protection authority signs crop certification on-chain. Cannot be forged. Critical for EAC agricultural export corridor.
CLI Available Now

Certificate of Origin
Chamber of commerce signs origin certification. Required for preferential tariffs under COMESA, AfCFTA, EAC trade agreements.
CLI Available Now

IoT / DePIN Anchor
